# Repuestos Cuchau

Tienda web de repuestos y accesorios para autos, hecha con React, TypeScript y Vite.

## Características

- Catálogo de productos con detalle de cada uno
- Carrito de compras
- Inicio de sesión y registro de usuarios
- Panel de administración: gestión de productos, pedidos y usuarios
- Blog, página "Nosotros" y formulario de contacto

## Tecnologías

- React 18
- TypeScript
- Vite
- React Router
- Bootstrap 5 y Bootstrap Icons

## Cómo ejecutarlo

Necesitas tener [Node.js](https://nodejs.org/) instalado.

```bash
npm install
npm run dev
```

Luego abre http://localhost:5173/ en tu navegador.

## Scripts

| Comando           | Descripción                          |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Inicia el servidor de desarrollo     |
| `npm run build`   | Genera la versión de producción      |
| `npm run preview` | Previsualiza la versión de producción |
