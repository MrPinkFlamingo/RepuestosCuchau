# 🚗 Repuestos Cuchau

Proyecto de maquetación web para una tienda de repuestos y accesorios automotrices. Este proyecto incluye toda la interfaz visual de la tienda (E-commerce) y un panel interno de gestión con distintos roles (Administrador y Vendedor).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Hoja de estilos personalizada (`style.css` con reglas limitadas).
* **Bootstrap 5:** Framework principal utilizado para el diseño responsive, sistema de grillas, tarjetas y componentes visuales.
* **JavaScript (Vanilla):** Utilizado para validaciones de formularios en el lado del cliente (Validación de RUT chileno Módulo 11, dominios de correo, formato de contraseñas, etc.) y control de acceso simulado.

## ⚙️ Características Principales

1. **Tienda Pública (Storefront):**
   * Inicio, Catálogo de Productos, Nosotros, Blog y Contactos.
   * Vistas de Detalles de Productos individuales (Ej. Baterías, Aceites, Pastillas).
2. **Sistema de Formularios:**
   * Login y Registro con validaciones estrictas y feedback visual de Bootstrap.
3. **Panel de Gestión Interno (Intranet):**
   * Vistas independientes que se adaptan según el Rol (Admin / Vendedor).
   * Tablas de datos para Gestión de Productos, Historial de Órdenes y Gestión de Usuarios.
   * Las vistas de administración restringen funcionalidades de manera dinámica.

## 🚀 Cómo Ejecutar el Proyecto

Dado que es un proyecto puramente Frontend (HTML, CSS, JS), no requiere de instalación de servidores locales ni bases de datos.

1. Clona o descarga el repositorio.
2. Navega hasta la carpeta del proyecto.
3. Abre el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Firefox, Edge, Safari).
4. Navega a través de los enlaces para visualizar todas las pantallas.
